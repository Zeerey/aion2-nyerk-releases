# Help improve Nyerk

[← Back to Nyerk](README.md)

Nyerk is actively developed. Clear bug reports, practical feature requests and carefully described comparisons help decide what to improve next.

## Choose the right report

| Need | Where to go |
| --- | --- |
| Something is broken | [Bug report](https://github.com/Zeerey/aion2-nyerk-releases/issues/new?template=bug_report.yml) |
| An idea for the application | [Feature request](https://github.com/Zeerey/aion2-nyerk-releases/issues/new?template=feature_request.yml) |
| A boss or event countdown disagrees with the game | [Timer mismatch](https://github.com/Zeerey/aion2-nyerk-releases/issues/new?template=timer_correction.yml) |
| Setup or a common problem | [Getting started](docs/GETTING_STARTED.md) / [Troubleshooting](docs/TROUBLESHOOTING.md) |
| Optional financial support | [Ko-fi](https://ko-fi.com/zeerey) |

Search [existing issues](https://github.com/Zeerey/aion2-nyerk-releases/issues) first. If yours is already reported, add new details there rather than opening a duplicate. Suggestions are welcome; response times and implementation dates are not guaranteed.

## Reporting from the app

Choose **Report a bug**, review the application summary, then continue to GitHub. You can add steps and screenshots before submitting. GitHub requires an account to create an issue.

A blank-issue route remains available so the app's prefilled report continues to work alongside the structured forms.

## Useful combat comparisons

Capture the same completed fight on both meters and include:

- Nyerk version and comparison-meter version.
- Final total damage, DPS and encounter duration.
- Whether both views cover all enemies or a single boss.
- Whether Nyerk started before login or during the fight.
- Whether the missing source is a player, a summon, an Actor label or a duplicate.

You do not need access to every skill or buff to help. One well-described example is valuable. Approximate peak DPS from memory can flag a problem, but it cannot establish exact damage or duration agreement.

## Keep reports safe to share

Issues are public. Review screenshots for names, chat, account details and other information you do not want published. Never attach passwords, tokens, full application-data folders or raw packet captures.

For an investigation that needs a recording, mention that a private capture exists and wait to agree on a suitable private transfer. No private upload service is provided by this repository. Do not post sensitive security details in a public issue; request a private contact route without including the sensitive details.

## Supporting development

Nyerk is free. [Ko-fi donations](https://ko-fi.com/zeerey) are optional support for continued development and do not guarantee a feature or priority support. Helpful testing and feedback are also appreciated.
