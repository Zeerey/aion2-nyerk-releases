# Aion 2 Nyerk downloads

Windows companion for AION 2 activities, pets, event timers and experimental combat tracking.

## Download

Open [Releases](https://github.com/Zeerey/aion2-nyerk-releases/releases) and choose the newest Windows x64 portable ZIP. Extract it and run **Aion2Nyerk.exe** or **Launch Nyerk.cmd**.

Windows 10/11 x64 and WebView2 are required. Live game tracking needs Npcap.

## In-app updates

Starting with **1.0.0-rc.2**, a download icon appears in the main window and companion popout. It glows only when a newer compatible release is available. Download first, then choose **Install & restart** when ready. The popout icon opens the update panel in the main window.

Checks run at startup and every four hours, with a manual check in the update panel. Saved characters, settings and recordings remain in `%APPDATA%/Aion2Nyerk`.

The standalone **Aion2Nyerk-Windows-x64.exe** asset is used by the updater. Portable ZIPs include launch instructions and third-party notices. Keep the application in a writable folder. Release candidates remain test builds; combat decoding is experimental.

This repository contains public compiled downloads and release information. Application source is maintained separately. No user captures, recordings, credentials or profiles belong here.
