# Public release highlights

[← Back to Nyerk](README.md)

This page highlights public milestones. The linked release pages contain the complete notes and downloads. Local RC29–RC31 work is tracked in the [roadmap](ROADMAP.md).

## RC28 — Combat accuracy and summon attribution

[Release notes and download](https://github.com/Zeerey/aion2-nyerk-releases/releases/tag/v1.0.0-rc.28)

Broader verified damage coverage, additional summon-owner recognition, clearer unresolved-source display and more reliable encounter timing. Delayed observations show **Catching up** instead of misleading DPS. Combat remains experimental.

## RC24 — Windows update failure handling

[Release notes](https://github.com/Zeerey/aion2-nyerk-releases/releases/tag/v1.0.0-rc.24)

Improved handling and reporting when Windows blocks the update helper. A security block is surfaced rather than repeatedly retried.

## RC21–RC23 — Identity and party-damage improvements

[RC21](https://github.com/Zeerey/aion2-nyerk-releases/releases/tag/v1.0.0-rc.21) · [RC22](https://github.com/Zeerey/aion2-nyerk-releases/releases/tag/v1.0.0-rc.22) · [RC23](https://github.com/Zeerey/aion2-nyerk-releases/releases/tag/v1.0.0-rc.23)

Stronger actor identity handling, better continuity during ongoing party combat and additional verified damage/recovery classifications.

## RC9 — Hourly update checks

[Release notes](https://github.com/Zeerey/aion2-nyerk-releases/releases/tag/v1.0.0-rc.9)

Checks at startup and every hour, with shared update indicators in the main window and companion popout.

## RC3–RC8 — Account pets and the companion popout

[Browse release history](https://github.com/Zeerey/aion2-nyerk-releases/releases)

Account-wide pet tracking, ranked player DPS, unrelated-combat filtering, popout input/transparency fixes and a compact layout that grows with its content.

## RC2 — Public downloads and in-app updates

[Release notes](https://github.com/Zeerey/aion2-nyerk-releases/releases/tag/v1.0.0-rc.2)

Public portable downloads and the in-app update workflow.
